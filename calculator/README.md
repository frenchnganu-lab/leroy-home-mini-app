# LEROY HOME — демонстрация конструктора

[Открыть демонстрацию](https://frenchnganu-lab.github.io/leroy-home-mini-app/calculator/)

Шкаф начинается с пустого корпуса. Выберите проём на модели или из списка.

- «Наполнение»: разделение по вертикали/горизонтали, фиксированные и переставные полки, ящики. Направляющие и ручки ящиков задаются в выбранном отсеке.
- «Фасады»: одна или две распашные створки, подъёмный либо откидной фасад. Направление, материал, оттенок, ручки и филёнка задаются для выбранного проёма.
- Материал и оттенок корпуса настраиваются отдельно. «Открыть фасады» показывает открывание в 3D.
- Доступны 2D, отмена/повтор, локальное сохранение и сброс «Пустой шкаф».

Исходники находятся в ветке `calculator-demo`. Для запуска: `npm install`, `npm run dev`; проверка модели: `node model-check.cjs`.

Статическая демонстрация скачивает конфигурацию с контактами в JSON. Автоматическая отправка менеджеру в ней не подключена. Стоимость и производственную совместимость уточняет конструктор.


Обновление: створки и ящики плавно открываются при наведении курсора в 3D и закрываются после ухода. Для сенсорного экрана остаётся кнопка открытия фасадов. Ввод количества начинается с 0; после ввода и применения «2» получается ровно два элемента в выбранном отсеке, повторное применение заменяет количество, а не умножает его. Поле допускает стирание и ручной ввод; 0 ничего не добавляет.
