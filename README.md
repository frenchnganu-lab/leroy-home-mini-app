# LEROY HOME — демонстрационный калькулятор

Статическая демонстрационная копия https://leroy-home-calculator.tenderrhino1.chatgpt.site/. Сохранены размеры, материалы, комплектующие, секции, декор, оттенки и интерактивный эскиз.

Контакты и комплектация скачиваются в JSON по нажатию кнопки. Передачи менеджеру, CRM, базы заявок и расчёта цены в демо нет.

## Запуск

Требуется Node.js 22.13 или новее.

```sh
npm install
npm run dev
```

## GitHub Pages

`docs/` содержит готовый сайт. В Settings → Pages выберите Deploy from a branch, ветку `calculator-demo` и папку `/docs`.
