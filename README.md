# LEROY HOME — калькулятор с редактором шкафа

Демонстрация: https://frenchnganu-lab.github.io/leroy-home-mini-app/calculator/

Шкаф: 3D/2D, отдельные отсеки, вложенное деление, полки и ящики, независимые фасады, отмена/повтор и сохранение черновика в браузере. Полная структура включена в скачиваемую заявку. Остальные категории и оформление сохранены. Это предварительная конфигурация, не производственная документация.

## Запуск

Node.js 22.13 или новее.

```sh
npm ci
npm run dev
npm run build
node model-check.cjs
```

Готовая сборка в `docs/`. Публичный сайт публикуется из папки `calculator/` основной ветки; исходники находятся в `calculator-demo`.

В демо контакты и параметры скачиваются в JSON. Автоматическая передача менеджеру и расчёт цены не подключены.

## Редактор шкафа

Шкаф начинается с пустого корпуса. В большом редакторе выберите проём на 3D-модели или 2D-проекции: вкладка «Наполнение» управляет делением и локальными полками/ящиками, вкладка «Фасады» — одной или двумя распашными створками, подъёмным и откидным фасадами. Тип, петли, материал, оттенок, ручки и филёнка сохраняются для каждого фасада отдельно. Направляющие и ручки ящиков задаются в выбранном отсеке. Материал и оттенок корпуса остаются в общих настройках. Старые общие разделы «Секции» и «Цвет фасада» для шкафа скрыты.

Проверка модели: `node model-check.cjs`. Существующие локально сохранённые проекты мигрируют без сброса геометрии. Версия 1 JSON поддерживает новые необязательные поля front, guides, handles.
